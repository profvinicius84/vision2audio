# Constraints Context

Record approved constraints that affect product, design, implementation or operation.

## Product constraints

- Android only.
- Built with .NET MAUI.

## Technical constraints

- Requires OTG camera support.
- Requires Bluetooth remote or keyboard trigger support.
- Requires GPS access for each capture.
- Requires internet connectivity to complete the request.
- No backend is allowed.

## Legal or compliance constraints

- No user account or authentication flow is in scope.

## Operational constraints

- The app must warn the user when offline.
- The app must keep a local history and allow clearing all entries.

## Security constraints

- OpenAI access must not introduce unnecessary client-side exposure beyond the approved direct-to-platform flow.
